# 学生管理系统

用 Python 实现的命令行学生信息管理系统,支持增删改查,成绩统计与分析

## 功能

- **添加学生**:录入学号、姓名、年龄、成绩、专业
- **查询学生**:支持按姓名、按成绩区间查询
- **删除学生**:按学号删除
- **修改数据**:按学号修改学生信息
- **成绩分析**:统计最高分、最低分、平均分、及格人数与及格率
- **成绩统计**:按成绩降序、姓名升序列出所有学生

## 项目结构

```
student_manager/
├── main.py              # 程序入口,负责主流程(菜单循环 + 功能分发)
├── student.json         # 数据文件,保存所有学生信息
├── README.md
└── utils/
    ├── __init__.py      # 包标记
    ├── menu.py          # 菜单显示
    ├── storage.py       # 数据读取与保存(JSON)
    └── my_fun.py        # 业务函数:增删改查与统计

```

## 运行环境

- Python 3.x
- 无需第三方库(仅使用标准库 `json`)

## 运行方法

```bash
python main.py
```

## 使用说明

运行后可根据菜单输入相应数字选择功能
```
 ######学生管理系统#######
 #      1.添加学生      #
 #      2.查询学生      #
 #      3.删除学生      #
 #      4.修改数据      #
 #      5.成绩分析      #
 #      6.成绩统计      # 
 #      0.退出系统      #
 #######################
```
## 数据存储

学生数据保存在 `student.json` 中,结构如下:

```json
{
    "001": {
        "id": "001",
        "name": "张三",
        "age": 20,
        "grades": 90,
        "major": "数学与应用数学"
    }
}
```
