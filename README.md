# 学生管理系统

用 Python 实现的命令行学生信息管理系统,支持增删改查、成绩分析与统计。

## 功能

- **添加学生**:录入学号、姓名、年龄、成绩、专业
- **删除学生**:按学号删除
- **修改学生**:按学号修改学生信息
- **查询学生**:支持按姓名、按成绩区间查询
- **成绩分析**:统计最高分、最低分、平均分、及格人数与及格率
- **成绩统计**:按成绩降序、姓名升序列出所有学生
- **退出系统**:结束程序

## 项目结构

```
student_manager/
├── main.py              # 程序入口,负责主流程(菜单循环 + 功能分发)
├── student.json         # 数据文件,保存所有学生信息
├── README.md            # 项目说明书
└── utils/
    ├── __init__.py      # 包标记
    ├── menu.py          # 菜单显示(menu_func)
    ├── storage.py       # 数据读取与保存(save_data / load_data)
    └── my_fun.py        # 业务函数:增删改查与统计
```

## 运行环境

- Python 3.10+(使用了 `match...case` 语法)
- 无需第三方库(仅使用标准库 `json`)

## 运行方法

```bash
python main.py
```

## 使用说明

运行后根据菜单输入数字(1-7)选择对应功能:

```text
########学生管理系统########
#      1.添加学生信息      #
#      2.删除学生信息      #
#      3.修改学生信息      #
#      4.查询学生信息      #
#      5.分析学生成绩      #
#      6.统计学生成绩      #
#      7.退出管理系统      #
###########################
```

### 输入规则

- 学号唯一:添加时若学号已存在,会提示重新输入
- 年龄需为大于 0 的整数
- 成绩范围为 0~100 的整数
- 按成绩范围查询时,需满足 0 ≤ 下限 ≤ 上限 ≤ 100

## 数据存储

学生数据保存在 `student.json` 中,结构如下:

```json
{
    "001": {
        "ID": "001",
        "name": "张三",
        "age": 20,
        "grade": 90,
        "major": "数学与应用数学"
    }
}
```

外层键为学号,内层字段含义:

| 字段 | 含义 |
|------|------|
| `ID` | 学号 |
| `name` | 姓名 |
| `age` | 年龄 |
| `grade` | 成绩 |
| `major` | 专业 |
